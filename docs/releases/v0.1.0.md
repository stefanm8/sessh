# sessh 0.1.0

The first sessh (session shell) release provides one browser-session manager
for Bitbucket Cloud, Jira Cloud, Confluence Cloud, and Microsoft Teams.

- Reuse authenticated Chromium profiles across commands and concurrent processes.
- Read repositories, pull requests, CI checks, Jira issues, and Confluence pages.
- Capture Teams messages locally and query them without a browser.
- Install prebuilt binaries on macOS/Linux, amd64/arm64, without Go or sudo.
- Verify downloaded archives with SHA-256 checksums; optionally install the
  matching Playwright driver and Chromium with `--with-browser`.

## Install

While the repository is private, use GitHub CLI authenticated with an account
that has repository access:

```sh
gh release download v0.1.0 -R stefanm8/sessh -p install.sh -O - | sh
```

Add `--with-browser` via `| sh -s -- --with-browser` for browser setup (requires
Node.js and npm). The default binary destination is `~/.local/bin/sessh`.
The release also includes a standalone browser setup script, four platform
archives, and a checksum manifest covering all assets except the manifest itself.

## Validation and compatibility

The release workflow runs Go formatting, module consistency, vet, race-enabled
tests, and native package installation checks on macOS and Linux before
publishing. Authentication against real service accounts remains a separate
validation step. The repository stays private during that validation.

Jira and Confluence require explicit site settings; Bitbucket requires an
explicit workspace. State lives under `~/.sessh`, configurable with
`SESSH_HOME`. See the migration guide in the archive for older `zai` state.
Native Windows is not supported. This is an independent, unofficial project.
